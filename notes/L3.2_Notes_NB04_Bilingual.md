# Step 1 — Frame the Test

*第 1 步——设计检验框架*

Before touching data, write down four things:

*碰数据之前，先写下四个要素：*

| Component / 要素 | Sarah's definition / Sarah 的定义 |
|---|---|
| **Null hypothesis H₀**<br>*原假设* | The coupon has **no effect** on 30-day repurchase rate<br>*优惠券对 30 天复购率**没有影响*** |
| **Alternative H₁**<br>*备择假设* | The coupon **increases** 30-day repurchase rate<br>*优惠券**提高** 30 天复购率* |
| **Outcome metric**<br>*结果指标* | Share of NEGATIVE-tagged customers who buy again within 30 days<br>*被标为负面的客户中，30 天内再次购买的比例* |
| **Two groups**<br>*两个组* | Control: no coupon · Treatment: coupon (random assignment)<br>*对照组：不发券 · 实验组：发券（随机分配）* |

## Understanding H₀

*理解 H₀*

H₀ is the "boring default": nothing happened. We **assume H₀ is true**, then ask how much the data contradicts it. If the contradiction is strong enough, we reject H₀.

*H₀ 是"无聊的默认假设"：什么都没发生。我们**先假设 H₀ 成立**，再看数据跟它有多矛盾。矛盾够大就拒绝 H₀。*

> 💡 **Courtroom analogy:** H₀ = "the defendant is not guilty". The prosecution needs **enough evidence** to overturn it. Not enough evidence → "not guilty", which **does not prove innocence**.
>
> *💡 **法庭类比**：H₀ = "被告无罪"。检方需要**足够证据**才能推翻。证据不足 → 判"无罪"，但这**不等于证明清白**。*

> 💡 **Audit analogy:** the default audit position is "the accounts are fairly stated". Only sufficient contrary evidence leads to a qualified opinion.
>
> *💡 **审计类比**：审计的默认立场是"账目公允"。只有找到足够的反证，才会出具保留意见。*

## Why only ONE metric?

*为什么只用一个指标？*

If you watch repurchase, revenue, satisfaction and complaints at once, one of them will look "significant" by luck. Fix one metric **in advance** to avoid cherry-picking.

*同时看复购率、收入、满意度、投诉率，总有一个会碰巧"显著"。**事先**只定一个指标，才能避免挑对自己有利的结果。*

*代码 ✅ 已运行*

BASELINE_REPURCHASE_RATE = 0.25   # control: 25% repurchase / 对照组 25% 复购

> *💡 **会计类比**：就像审计前先定**重要性水平**：实验开始前先定"多大的效果才有商业意义"。*

# Step 2 — Run the Experiment

*第 2 步——运行实验*

```python
np.random.seed(42)
control_repurchases   = np.random.binomial(n=1, p=0.25, size=400)
treatment_repurchases = np.random.binomial(n=1, p=0.33, size=400)
control_rate   = control_repurchases.mean()
treatment_rate = treatment_repurchases.mean()
```

**Output / 输出：**

```
Control group (no coupon):        100 / 400 = 25.00%
Treatment group (received coupon): 130 / 400 = 32.50%
Observed difference: +7.50% (32.50% vs 25.00%)
```

## Random assignment

*随机分配*

Customers are assigned to groups **at random**, so the only systematic difference is the coupon. Other factors average out.

*客户被**随机**分到两组，所以两组唯一的系统性差别就是优惠券。其他因素会被平均掉。*

→ This is why A/B tests show **causation**, not just correlation.

*→ 这就是 A/B 测试能证明**因果关系**而不只是相关性的原因。*

## ⚠️ Percentage points vs percent

*⚠️ 百分点 vs 百分比*

| Term / 说法 | Calculation / 计算 | Result / 结果 |
|---|---|---|
| **Percentage points (pp)**<br>*百分点* | 32.5% − 25.0% | **+7.5 pp** |
| **Relative change**<br>*相对变化* | (32.5 − 25) / 25 | **+30%** |

The notebook prints "+7.50%", but strictly it is **+7.5pp**. Always say which one you mean.

*Notebook 输出 "+7.50%"，严格来说是 **+7.5pp**。报告时一定要说清楚。*

> 💡 Like "gross margin rose from 25% to 32.5%": say "up 7.5 percentage points", not "up 7.5%".
>
> *💡 就像"毛利率从 25% 升到 32.5%"：应说"上升 7.5 个百分点"，不是"上升 7.5%"。*

`:+.2%` in an f-string always shows the sign (+/−).

*f-string 的 `:+.2%` 会永远显示正负号。*

# Statistical vs Practical Significance

*统计显著 vs 实际意义*

Ask two **separate** questions:

*分开问两个问题：*

1. Is the effect **statistically credible**? → **p-value**

   *效果在统计上**可信**吗？→ **p 值***

2. Is it **large enough to act on**? → **effect size**

   *效果**大到值得行动**吗？→ **效应量***

| Variant / 方案 | Conversion / 转化率 | Business value / 商业意义 |
|---|---|---|
| A | 10.0% → **10.1%** | Likely too small<br>*可能太小* |
| B | 10.0% → **12.5%** | Meaningful<br>*有意义* |

With a big enough sample, **both** can be significant; only B matters.

*样本够大时，**两个**都可能显著；但只有 B 真正有意义。*

# Step 3 — Two-proportion z-test

*第 3 步——双比例 z 检验*

## Code ✅ Run

*代码 ✅ 已运行*

```python
# ① Pooled proportion (assume H₀: both groups the same) / 合并比例（假设 H₀）
p_pool = (control_repurchases_n + treatment_repurchases_n) / (N_CONTROL + N_TREATMENT)

# ② Standard error of the difference / 差异的标准误
se = np.sqrt(p_pool * (1 - p_pool) * (1/N_CONTROL + 1/N_TREATMENT))

# ③ z statistic: how many SEs apart? / z 统计量：差距是几个标准误？
z_stat = (treatment_rate - control_rate) / se

# ④ one-sided p-value / 单尾 p 值
p_value_z = 1 - st.norm.cdf(z_stat)
```

## Worked by hand

*手算验证*

**① Pooled proportion / 合并比例**

```
p_pool = (100 + 130) / (400 + 400) = 230 / 800 = 0.2875
```

Why pool? The test starts by **assuming H₀**: the coupon does nothing, so both groups share one repurchase rate.

*为什么合并？检验的出发点是**假设 H₀ 成立**：优惠券没用，两组共享同一个复购率。*

**② Standard error / 标准误**

```
SE = √( 0.2875 × 0.7125 × (1/400 + 1/400) ) = √( 0.2048 × 0.005 ) = 0.0320
```

Same idea as NB03's `√(p(1−p)/n)`, but for the **difference** of two groups, hence `1/n₁ + 1/n₂`. Meaning: even with no effect, the groups would differ by ~3.2pp purely by chance.

*和 NB03 的 `√(p(1−p)/n)` 同一思路，只是比较的是两组的**差**，所以是 `1/n₁ + 1/n₂`。意思是：即使没效果，两组纯粹因随机也会相差约 3.2pp。*

**③ z statistic / z 统计量**

```
z = (0.325 − 0.250) / 0.0320 = 2.343
```

The observed gap is **2.34×** the random wobble. This is the **Z-score from NB02**, now measuring how unusual a *difference* is.

*观察到的差距是随机波动的 **2.34 倍**。这就是 **NB02 的 Z 分数**，只是现在衡量的是"差距"有多不寻常。*

**④ p-value / p 值**

```python
p_value = 1 - st.norm.cdf(2.343)    # = 0.0096
```

| Function / 函数 | Meaning / 意思 |
|---|---|
| `st.norm.cdf(z)` | Probability of a value **below** z (left area) ≈ 0.9904<br>*小于 z 的概率（左侧面积）* |
| `1 − cdf(z)` | Probability **above** z (right tail) ≈ **0.0096**<br>*大于 z 的概率（右尾面积）* |

> 💡 **Excel:** `=1 - NORM.S.DIST(2.343, TRUE)` = 0.0096

## One-sided vs two-sided

*单尾 vs 双尾*

| | H₁ | Tail / 尾部 | p here / 这里的 p |
|---|---|---|---|
| **One-sided**<br>*单尾* | Coupon **increases** repurchase<br>*优惠券**提高**复购* | Right only<br>*只看右尾* | **0.0096** |
| **Two-sided**<br>*双尾* | Coupon **changes** repurchase<br>*优惠券**改变**复购* | Both<br>*两边* | 0.0192 |

Two-sided is more conservative (p doubles) and more common in practice. Both are < 0.05 here.

*双尾更保守（p 值翻倍），实务更常用。这里两者都 < 0.05。*

**Output / 输出：**

```
Pooled proportion:         0.2875
Standard error:            0.0320
Z-statistic:               2.343
P-value (one-sided):       0.0096

Result: STATISTICALLY SIGNIFICANT (p < 0.05)
Conclusion: We reject the null hypothesis.
```

## Decision rule (α = 0.05)

*决策规则（α = 0.05）*

| p < 0.05 | p ≥ 0.05 |
|---|---|
| **Reject H₀**: evidence of a real effect<br>***拒绝 H₀**：有证据表明效果真实* | **Fail to reject H₀**: not enough evidence. ⚠️ **Not** "no effect"<br>***不能拒绝 H₀**：证据不足。⚠️ **不等于**"没有效果"* |

`α = 0.05` is the **significance level**, set in advance, like materiality.

*`α = 0.05` 是**显著性水平**，事先定好，就像重要性水平。*

`if / else` works like Excel `IF()` but runs multiple lines; Python uses **indentation** to know which lines belong to each branch.

*`if / else` 像 Excel 的 `IF()`，但可执行多行；Python 靠**缩进**判断哪些行属于哪个分支。*

# Step 4 — Three p-value Mis-readings

*第 4 步——三种 p 值误读*

🏠 Take-home, but frequently tested in interviews and exams.

*🏠 可回家看，但面试和考试常考。*

## ❌ Mis-reading 1: "p = 0.03 means a 3% chance H₀ is true"

*❌ 误读 1："p = 0.03 表示 H₀ 为真的概率是 3%"*

```
p = P(data | H₀)     ✅ probability of data this extreme, GIVEN H₀ is true / 假设 H₀ 为真，出现这组数据的概率
    P(H₀ | data)     ❌ probability H₀ is true, given the data (needs Bayes) / 看到数据后 H₀ 为真的概率（需要贝叶斯）
```

✅ "**If** the coupon had zero effect, we'd see a result this extreme only 3% of the time."

*✅ "**如果**优惠券毫无作用，我们只有 3% 的机会看到这么极端的结果。"*

> 💡 "P(wet ground | rain)" ≠ "P(rain | wet ground)": the ground could be wet from a street sweeper.
>
> *💡 "下雨时地面湿的概率" ≠ "地面湿时下过雨的概率"：也可能是洒水车。*

## ❌ Mis-reading 2: "p < 0.05, so the effect is large and important"

*❌ 误读 2："p < 0.05，所以效果很大很重要"*

With a big enough sample, tiny differences become significant. ✅ **Always report effect size**: "+2.5pp (p = 0.031)".

*样本够大时，微小差异也会显著。✅ **永远报告效应量**："+2.5pp（p = 0.031）"。*

## ❌ Mis-reading 3: "p = 0.08, so the coupon doesn't work"

*❌ 误读 3："p = 0.08，所以优惠券没用"*

p = 0.08 means **insufficient evidence**, not that H₀ is true. The effect may be real but undetectable at this sample size.

*p = 0.08 表示**证据不足**，不代表 H₀ 为真。效果可能真实存在，只是这个样本量检测不出来。*

> **"Absence of evidence is not evidence of absence."**
>
> ***"没有证据 ≠ 证明没有。"***

✅ "No significant evidence at the 0.05 level. We can't conclude the coupon has no effect; the sample may be too small. Recommend extending the test."

*✅ "在 0.05 水平下没有发现显著证据。不能断定优惠券无效，样本可能太小。建议延长测试。"*

## The hypothesis testing family

*假设检验家族*

| Test / 检验 | Question / 问题 | Where in course / 课程位置 |
|---|---|---|
| **One-sample z/t-test**<br>*单样本 z/t 检验* | Different from a known reference value?<br>*与已知参考值不同吗？* | L05 anomaly detection<br>*L05 异常检测* |
| **Two-sample z-test (A/B)**<br>*双样本 z 检验* | Does an intervention change a rate between two **independent** groups?<br>*干预是否改变两个**独立**组的比率？* | **This lesson**<br>***本课*** |
| **Paired t-test**<br>*配对 t 检验* | Two conditions on the **same** subjects?<br>***同一批**对象在两种条件下不同吗？* | L07–08 model A vs B<br>*L07–08 模型对比* |
| **Chi-square test**<br>*卡方检验* | Are two categorical distributions the same?<br>*两个分类分布相同吗？* | L10 prompt evaluation<br>*L10 提示词评估* |

Same logic every time: set H₀ → compute a test statistic → get a p-value.

*逻辑都一样：设定 H₀ → 算检验统计量 → 得到 p 值。*

`errorbar`: draws a point with lines up and down to the CI bounds; `capsize` = width of the end caps.

**Group CIs / 各组区间：**

```
Control   : 25.0% ± 1.96 × √(0.25 × 0.75 / 400)   = [20.8%, 29.2%]
Treatment : 32.5% ± 1.96 × √(0.325 × 0.675 / 400) = [27.9%, 37.1%]
```

### 🔍 Key finding: CIs overlap, yet the test is significant

*🔍 关键发现：区间有重叠，但检验仍然显著*

The intervals overlap (27.9%–29.2%), yet p = 0.0096.

*两个区间重叠（27.9%–29.2%），但 p = 0.0096。*

- **No overlap** → definitely significant ✅

  ***不重叠** → 一定显著 ✅*

- **Overlap** → **not necessarily** non-significant ⚠️; run the formal test.

  ***有重叠** → **不一定**不显著 ⚠️；要做正式检验。*

Why: comparing two CIs effectively **adds** the two errors, but the true error of a difference is **√(SE₁² + SE₂²)**, which is smaller. Eyeballing overlap is too conservative. (Assignment Tier 2 asks about this.)

*原因：比较两个区间相当于把两边误差**直接相加**，但差异的真实误差是 **√(SE₁² + SE₂²)**，更小。所以看重叠太保守。（作业 Tier 2 会考。）*

**The bar chart alone hides uncertainty** and can make you over-confident.

***单看柱状图会隐藏不确定性**，容易让人过度自信。*

### ⚠️ Coding trap: variable overwriting

*⚠️ 代码陷阱：变量被覆盖*

The loop reuses `se = ...`, overwriting Step 3's `se` (0.0320) with the treatment group's SE (~0.0234). Harmless here, but a common bug. Use distinct names such as `se_group`.

*循环里重复用了 `se = ...`，把 Step 3 的 `se`（0.0320）覆盖成实验组的 SE（约 0.0234）。这里无害，但是常见 bug。请用不同名字，例如 `se_group`。*

# Code Cheat Sheet

```python
# ---- Simulate two groups / 模拟两组 ----
control   = np.random.binomial(1, 0.25, 400)
treatment = np.random.binomial(1, 0.33, 400)

# ---- Two-proportion z-test / 双比例 z 检验 ----
p_pool = (control.sum() + treatment.sum()) / (len(control) + len(treatment))
se     = np.sqrt(p_pool * (1 - p_pool) * (1/len(control) + 1/len(treatment)))
z      = (treatment.mean() - control.mean()) / se
p_one  = 1 - st.norm.cdf(z)            # one-sided (increase) / 单尾（提高）
p_one_lower = st.norm.cdf(z)           # one-sided (decrease) / 单尾（降低）
p_two  = 2 * (1 - st.norm.cdf(abs(z))) # two-sided / 双尾

# ---- Decision / 决策 ----
alpha = 0.05
if p_one < alpha:
    print("Reject H0")
else:
    print("Fail to reject H0")

# ---- Per-group CI + error bar / 各组区间 + 误差条 ----
se_g = np.sqrt(rate * (1 - rate) / n)
ax.errorbar(x=0, y=rate, yerr=[[1.96*se_g], [1.96*se_g]], fmt='o', capsize=8)

# ---- f-string ----
f"{diff:+.2%}"     # always show sign / 显示正负号
```

⚠️ For a **decrease** (e.g. complaint rate in the assignment), use `st.norm.cdf(z)` instead of `1 - st.norm.cdf(z)`.

*⚠️ 如果检验的是**下降**（例如作业里的投诉率），要用 `st.norm.cdf(z)`，不是 `1 - st.norm.cdf(z)`。*

# Key Takeaways

*核心要点*

1. **Frame the test first:** H₀, H₁, ONE metric, two randomised groups, and a minimum meaningful effect.

   ***先设计框架**：H₀、H₁、**一个**指标、两个随机分组，加上最小有意义效果。*

2. **Random assignment** is what lets an A/B test show causation.

   ***随机分配**让 A/B 测试能证明因果关系。*

3. **z = difference / SE**: the NB02 Z-score applied to a difference.

   ***z = 差距 / 标准误**：NB02 的 Z 分数用在"差距"上。*

4. **p-value = P(data this extreme | H₀)**, not P(H₀ | data).

   ***p 值 = P(如此极端的数据 | H₀)**，不是 P(H₀ | 数据)。*

5. **p < 0.05 → reject H₀; p ≥ 0.05 → insufficient evidence ≠ no effect.**

   ***p < 0.05 → 拒绝 H₀；p ≥ 0.05 → 证据不足 ≠ 没有效果。***

6. **Always report effect size with the p-value.** Significance ≠ importance.

   ***报告 p 值时务必同时报告效应量。**显著 ≠ 重要。*

7. **Say pp, not %,** for differences between rates.

   ***比率之间的差距要说 pp，不要说 %。***

8. **Overlapping CIs don't prove non-significance**: run the formal test.

   ***区间重叠不代表不显著**：要做正式检验。*
