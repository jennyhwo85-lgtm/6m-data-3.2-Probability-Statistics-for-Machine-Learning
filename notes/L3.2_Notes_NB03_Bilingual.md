# Part 1 — Scenario & Simulated Labelling

*第 1 部分——场景与模拟标注*

## Scenario

*故事背景*

Sarah hand-labelled 200 reviews and compared them with the model. The model agreed 167 times: **83.5% ≈ 84%**.

*Sarah 亲手标注了 200 条评论，与模型比较。模型答对 167 条：**83.5% ≈ 84%**。*

Priya: **"So the model is EXACTLY 84% accurate?"** With a different 200 reviews, would Sarah get 79%? 90%?

*Priya：**"所以模型准确率正好是 84%？"** 换另外 200 条，会不会是 79%？或 90%？*

→ This is the **confidence interval** problem.

*→ 这就是**置信区间**要解决的问题。*

## Setup: one new import

*Setup：新增一个导入*

```python
import scipy.stats as st    # ready-made statistics formulas / 现成的统计公式库
```

## Simulate the 200 labels ✅ Run

*模拟 200 条标注 ✅ 已运行*

```python
np.random.seed(42)
TRUE_ACCURACY = 0.83    # the "truth", known only in simulation / 只有模拟中才知道的真实值
SAMPLE_SIZE   = 200

correct_predictions = np.random.binomial(n=1, p=TRUE_ACCURACY, size=SAMPLE_SIZE)
sample_accuracy = correct_predictions.mean()   # 0.835 → proportion / 比例
correct_count   = correct_predictions.sum()    # 167   → count / 个数
```

| Argument / 参数 | Meaning / 意思 |
|---|---|
| `n=1` | Flip one "coin" each time<br>*每次只抛一次硬币* |
| `p=0.83` | 83% chance of 1 (correct), 17% of 0 (wrong)<br>*83% 机会是 1（答对），17% 是 0（答错）* |
| `size=200` | Do it 200 times<br>*做 200 次* |

`binomial` with `n=1` is a **Bernoulli trial**: only two outcomes, right or wrong.

*`n=1` 的二项分布叫 **Bernoulli（伯努利）试验**：只有对或错两种结果。*

> 💡 **Audit analogy:** this is **attribute sampling**. Check 200 vouchers, 1 = compliant, 0 = not. Compliance rate = compliant ÷ 200.
>
> *💡 **审计类比**：这就是**属性抽样**。抽查 200 张凭证，1 = 合规，0 = 不合规。合规率 = 合规张数 ÷ 200。*

**Output / 输出：**

```
Hand-labelled reviews:  200
Model agreed with Sarah: 167  (83.5%)
Sarah reports: '84% accuracy' (she got 84%)
(The TRUE underlying accuracy we set in simulation: 83%)
Sarah's estimate is close to the truth.
```

### Conditional expression

*条件表达式*

```python
{'close' if abs(sample_accuracy - TRUE_ACCURACY) < 0.03 else 'off'}
```

`A if condition else B` = Excel `=IF(ABS(B2-B1)<0.03, "close", "off")`.

*`A if 条件 else B` = Excel 的 `=IF(ABS(B2-B1)<0.03, "close", "off")`。*

## 🔑 Two different numbers

*🔑 两个不同的数字*

| | Value / 数值 | Who knows it? / 谁知道？ |
|---|---|---|
| **True accuracy**<br>*真实准确率* (population parameter / 总体参数) | 83% | Only "God". **Never known** in real life<br>*只有"上帝"知道，现实中**永远不知道*** |
| **Sample accuracy**<br>*样本准确率* (point estimate / 点估计) | 83.5% | Sarah, from her 200 reviews<br>*Sarah 从 200 条样本算出* |

The simulation lets us play God: set the truth, then see how well sampling estimates it.

*模拟让我们扮演上帝：先设定真实值，再看抽样能估得多准。*

# Part 2 — Repeat the Experiment 1,000 Times

*第 2 部分——把实验重复 1,000 次*

## Code ✅ Run

*代码 ✅ 已运行*

```python
accuracy_estimates = []                     # empty list / 空列表
for _ in range(N_SIMULATIONS):              # repeat 1,000 times / 重复 1,000 次
    sample = np.random.binomial(n=1, p=TRUE_ACCURACY, size=SAMPLE_SIZE)
    accuracy_estimates.append(sample.mean())    # add to list / 加进列表

accuracy_estimates = np.array(accuracy_estimates)   # list → numpy array / 列表 → 数组
```

| Syntax / 写法 | Meaning / 意思 |
|---|---|
| `[]` | Empty list<br>*空列表* |
| `for _ in range(1000):` | Repeat 1,000 times; `_` = "counter not needed"<br>*重复 1,000 次；`_` 表示不需要用到计数* |
| `.append(x)` | Add x to the end of the list<br>*把 x 加到列表最后* |
| `np.array(...)` | Convert so `.mean()`, `.std()` work<br>*转成数组，才能用 `.mean()`、`.std()`* |
| `np.percentile(x, 2.5)` | 2.5th percentile<br>*第 2.5 百分位* |

Each loop = one **parallel universe** where Sarah labelled a different 200 reviews.

*每次循环 = 一个**平行宇宙**：Sarah 标注了另外 200 条评论。*

> 💡 **Audit analogy:** 1,000 auditors each independently sample 200 vouchers from the same population. Each gets a slightly different compliance rate.
>
> *💡 **审计类比**：1,000 位审计员各自从同一总体独立抽 200 张凭证，每人算出的合规率都略有不同。*

**My output / 我的输出：**

```
Spread of estimates (standard deviation): 0.0269
Min: 0.755  |  Max: 0.905
95% of estimates fall between: 0.775 and 0.880
```

⚠️ The repo's saved output shows std 0.0265, min 0.740, max 0.900. This cell doesn't reset the seed, so small differences are normal. The **95% range is identical**.

*⚠️ Repo 保存的输出是 std 0.0265、min 0.740、max 0.900。这一格没有重设 seed，所以略有差异是正常的。**95% 范围完全相同**。*

## What the chart shows

*图表告诉我们什么*

1. **Bell-shaped (normal)** even though each review is only 0 or 1 → the **Central Limit Theorem**.

   ***钟形（正态）**，虽然每条评论只有 0 或 1 → 这就是**中心极限定理**。*

2. **The spread is real:** one sample of 200 could give ~77.5% to ~88%. "84%" is a **point estimate**, not a fact.

   ***波动是真实的**：一次 200 条的样本可能得出约 77.5% 到 88%。"84%" 是**点估计**，不是事实。*

3. **The centre equals the truth** (mean 0.830) → the estimate is **unbiased**.

   ***中心等于真实值**（平均 0.830）→ 估计是**无偏的**。*

4. **Gaps between bars (comb look):** accuracy can only be k/200 (steps of 0.005), but 40 bins are narrower than that, so some bins are empty. This is a feature of **discrete data**, not an error.

   ***柱子之间有空隙（梳子状）**：准确率只能是 k/200（每步 0.005），但 40 个 bins 比这更窄，有些 bin 是空的。这是**离散数据**的特点，不是错误。*

5. The legend says "Sarah's single estimate: 0.83" because `:.2f` rounds 0.835. The green line sits at the correct 0.835.

   *图例写 0.83 是因为 `:.2f` 把 0.835 四舍五入了。绿线位置才是准确的 0.835。*

## 🔗 The bridge to the formula

*🔗 通往公式的桥梁*

```
Simulated std              ≈ 0.0269
Formula SE = √(0.83 × 0.17 / 200) = 0.0266
```

They match! In real life we **don't need to repeat the experiment 1,000 times**: one sample's p and n plus a formula tell us how much the estimate would wobble.

*两者几乎一样！现实中**不需要真的重复 1,000 次**：只要一次样本的 p 和 n，用公式就能算出估计值会波动多少。*

⚠️ The notebook calls this "bootstrapping", but it is really **simulation from a known truth**. True bootstrapping resamples *your own sample* with replacement (see `optional_extensions.ipynb`).

*⚠️ Notebook 把这叫 "bootstrapping"，其实是**从已知真实值做模拟**。真正的 bootstrapping 是从*自己的样本*有放回重抽（见 `optional_extensions.ipynb`）。*

# Part 3 — The 95% Confidence Interval

*第 3 部分——95% 置信区间*

## Definition

*定义*

> A 95% CI is a range that, if you repeated the experiment many times, would contain the true value about 95% of the time.
>
> *95% 置信区间是这样一个范围：如果把实验重复很多次，约 95% 的区间会包含真实值。*

**Election poll analogy:** "Party A 43%, ±3 points, 95% confidence."

***选举民调类比**："A 党 43%，±3 个百分点，95% 置信度。"*

## Formula

*公式*

```
SE    = √( p̂ × (1 − p̂) / n )     ← standard error / 标准误
Lower = p̂ − 1.96 × SE
Upper = p̂ + 1.96 × SE
```

| Symbol / 符号 | Meaning / 意思 |
|---|---|
| **p̂** ("p-hat") | Sample proportion (0.835); the ^ means "estimate"<br>*样本比例（0.835）；^ 表示"估计值"* |
| **n** | Sample size (200)<br>*样本量（200）* |
| **1.96** | 95% of a normal distribution lies within ±1.96σ (the "2" in the 68–95–99.7 rule)<br>*正态分布中 95% 落在 ±1.96σ 内（即 68–95–99.7 法则里的"2"）* |

## Code ✅ Run

*代码 ✅ 已运行*

```python
p_hat = sample_accuracy    # 0.835
n     = SAMPLE_SIZE        # 200
se = np.sqrt(p_hat * (1 - p_hat) / n)      # np.sqrt = Excel SQRT()
margin_of_error = 1.96 * se
ci_lower = p_hat - margin_of_error
ci_upper = p_hat + margin_of_error
```

**Output / 输出：**

```
Sarah's sample accuracy (p̂):    83.50%
Sample size (n):                200
Standard error (SE):            0.0262
Margin of error (1.96 × SE):    0.0514  (5.1%)

95% Confidence Interval:        [78.36%, 88.64%]

Sarah can now write in her report:
  '84% accuracy (95% CI: 78%–89%)'

Compare to the true accuracy we set: 0.83
Is the true accuracy inside the interval? True
```

### Why SE = 0.0262 here, not 0.0266?

*为什么这里 SE 是 0.0262，不是 0.0266？*

- 0.0266 uses the **true** p = 0.83 (God's view).

  *0.0266 用的是**真实值** p = 0.83（上帝视角）。*

- 0.0262 uses the **sample** p̂ = 0.835: the only number we have in real life.

  *0.0262 用的是**样本值** p̂ = 0.835：现实中唯一能用的数字。*

### Small code notes

*代码小细节*

- `ci_lower <= TRUE_ACCURACY <= ci_upper`: chained comparison = Excel `=AND(B1<=B2, B2<=B3)`.

  *连续比较 = Excel 的 `=AND(B1<=B2, B2<=B3)`。*

- Yellow boxes around `×` and `–` in VS Code: special Unicode characters inside strings. Harmless.

  *VS Code 里 `×` 和 `–` 的黄框：字符串里的特殊 Unicode 字符，不影响运行。*

## How Sarah should report it

*Sarah 应该怎么报告*

> ❌ "Model accuracy is 84%."
>
> *❌ "模型准确率 84%。"*
>
> ✅ "Model accuracy is 84% (95% CI: 78%–89%), based on 200 hand-labelled reviews."
>
> *✅ "模型准确率 84%（95% CI：78%–89%），基于 200 条人工标注的评论。"*

> 💡 **Audit analogy:** audit reports don't say "error rate 2%"; they say "based on sampling, at 95% confidence the upper error limit is X%".
>
> *💡 **审计类比**：审计报告不会只说"差错率 2%"，而是说"根据抽样，在 95% 置信水平下，差错率上限为 X%"。*

## Section Summary

*本节总结*

| Concept / 概念 | Meaning / 意思 |
|---|---|
| **Sampling**<br>*抽样* | Measure a subset to estimate the whole; model evaluation on a test set is sampling<br>*用部分估计整体；在测试集上评估模型就是抽样* |
| **Standard Error**<br>*标准误* | How much estimates vary between samples; larger n → smaller SE<br>*估计值在不同样本间的波动；n 越大 SE 越小* |
| **Confidence Interval**<br>*置信区间* | The honest way to report: "84% (95% CI: 78%–89%)"<br>*诚实的报告方式* |
| **The mis-reading**<br>*误读* | 95% CI ≠ "95% probability the truth is in this range"<br>*95% CI ≠ "真实值有 95% 概率在区间里"* |

# Extension A — CLT with Dice

*扩展 A——用骰子演示中心极限定理*

## Why dice?

*为什么用骰子？*

One die gives 1–6 with equal chance: a **uniform** (flat) distribution, nothing like a bell. If even its *averages* become bell-shaped, the CLT works for any shape.

*一颗骰子 1–6 每个点数机会相同：**均匀分布**（平的），一点都不像钟形。如果连它的*平均值*都变成钟形，就证明 CLT 对任何形状都成立。*

> **Skittles analogy:** a jar with lopsided colours. Grab 30, count the reds, put back, repeat 1,000 times → the red counts form a bell curve.
>
> ***彩虹糖类比**：罐里颜色比例很不均匀。每次抓 30 颗数红色，放回，重复 1,000 次 → 红色数量形成钟形。*

## Code ✅ Run

*代码 ✅ 已运行*

```python
for i, sample_size in enumerate([1, 5, 30]):
    rolls = np.random.randint(1, 7, size=(n_experiments, sample_size))
    means = rolls.mean(axis=1)
    ax = axes[i]
    ax.hist(means, bins=30, density=True)
    if sample_size >= 5:
        x = np.linspace(means.min(), means.max(), 100)
        normal_curve = st.norm.pdf(x, means.mean(), means.std())
        ax.plot(x, normal_curve, 'b-', label='Normal fit')
```

| Syntax / 写法 | Meaning / 意思 |
|---|---|
| `enumerate([1, 5, 30])` | Gives index **and** value: (0,1), (1,5), (2,30)<br>*同时给出编号**和**值* |
| `randint(1, 7)` | Random integers 1–6. ⚠️ Upper bound 7 is **excluded**<br>*随机整数 1–6。⚠️ 上限 7 **不包含*** |
| `size=(2000, 30)` | 2,000 rows (experiments) × 30 columns (dice)<br>*2,000 行（实验）× 30 列（骰子）* |
| `.mean(axis=1)` | Average **across each row** → 2,000 means<br>*每一**行**横着求平均 → 2,000 个平均值* |
| `.mean(axis=0)` | Average **down each column** → 30 means<br>*每一**列**竖着求平均 → 30 个平均值* |
| `np.linspace(a, b, 100)` | 100 evenly spaced points from a to b<br>*a 到 b 之间均匀取 100 个点* |
| `st.norm.pdf(x, mean, std)` | Height of the normal curve at x<br>*正态曲线在 x 处的高度* |
| `density=True` | Bar height = density (total area = 1), so it can be compared with the curve<br>*柱高 = 密度（总面积 = 1），才能与曲线比较* |

> 💡 **Excel analogy:** `axis=1` = add `=AVERAGE(A2:AD2)` at the end of each row and fill down 2,000 rows.
>
> *💡 **Excel 类比**：`axis=1` = 在每一行最右边加 `=AVERAGE(A2:AD2)`，往下拉 2,000 行。*

## What the three charts show

*三张图告诉我们什么*

| Chart / 图 | Dice per roll / 每次几颗 | Shape / 形状 | X-axis range / X 轴范围 |
|---|---|---|---|
| Left / 左 | n = 1 | **Flat** (uniform); 6 separate bars<br>***平的**（均匀）；6 根分开的柱子* | 1–6 |
| Middle / 中 | n = 5 | **Humping**, near the normal curve<br>***开始隆起**，接近正态曲线* | 1–6 (wide / 宽) |
| Right / 右 | n = 30 | **Bell-shaped** and much **narrower**<br>***钟形**，而且**窄很多*** | 2.5–4.5 |

**Why is the n = 30 curve taller?** (peak ~1.25 vs ~0.52) With `density=True` the area is always 1. Narrower → must be taller.

***为什么 n = 30 的曲线更高？**（峰值约 1.25 对比约 0.52）`density=True` 让面积永远 = 1。变窄了 → 只能长高。*

**How much narrower?** One die's std ≈ 1.71:

***窄了多少？** 一颗骰子的标准差 ≈ 1.71：*

```
n = 5  :  SE = 1.71 / √5  ≈ 0.76
n = 30 :  SE = 1.71 / √30 ≈ 0.31
```

6× the dice → only ~2.4× narrower (√6 ≈ 2.45): the **√n rule**.

*骰子数 ×6 → 只窄了约 2.4 倍（√6 ≈ 2.45）：这就是 **√n 法则**。*

## 🔗 Link to Sarah

*🔗 和 Sarah 的关系*

Each review is 0 or 1, not normal, just like a die. But the **average of 200** is normal, **so Sarah can use the normal-based `1.96 × SE` formula**.

*每条评论只有 0 或 1，不是正态，就像骰子一样。但 **200 条的平均值**是正态的，**所以 Sarah 才能用基于正态分布的 `1.96 × SE` 公式**。*

→ **The CLT is the reason the CI formula works.**

*→ **CLT 是置信区间公式成立的前提。***

## 🔍 Advanced nuance

*🔍 进阶细节*

| | Method / 做法 |
|---|---|
| **This chart**<br>*这张图* | Fix **one** interval; count how many of 1,000 **estimates** fall in it<br>*固定**一个**区间，看 1,000 个**估计值**有多少掉进去* |
| **Strict definition**<br>*严格定义* | Build **one interval per simulation**; count how many **contain the truth**<br>*每次模拟**各算一个区间**，看多少个**包含真实值*** |

Here they agree because Sarah's 83.5% happens to be close to 83%. If she had drawn 78%, this chart's fraction would drop well below 95%, yet the method's 95% reliability would still hold.

*这里两者差不多，是因为 Sarah 的 83.5% 碰巧接近 83%。如果她抽到 78%，这张图的比例会明显低于 95%，但方法的 95% 可靠性依然成立。*

## 🚨 The most common mis-reading

*🚨 最常见的误读*

> ❌ "There is a 95% probability that the true accuracy is between 78% and 89%."
>
> *❌ "真实准确率有 95% 的概率落在 78% 到 89% 之间。"*
>
> ✅ "If we repeated this labelling exercise many times, 95% of the intervals we'd compute would contain the true accuracy."
>
> *✅ "如果把这个标注实验重复很多次，所算出的区间中有 95% 会包含真实准确率。"*

**Why?** The true accuracy is a **fixed number**: it is either in the interval or not. What varies is the **interval**. The 95% describes the **method**, not this one interval.

***为什么？** 真实准确率是**固定的数**：要么在区间里，要么不在。会变的是**区间**。95% 描述的是**方法**，不是这一个区间。*

> 💡 **Marksman analogy:** a shooter hits the bullseye 95 times in 100.
> - "**This shooter** has a 95% hit rate" ✅ (describes the method / skill)
> - After firing: "**this shot** has a 95% chance of having hit" ❌: it either hit or missed; we just haven't looked yet.
>

## The √n rule

*√n 法则*

- 50 → 200 (**×4**): width 20.6% → 10.3%, **halved**.

  *50 → 200（**×4**）：宽度 20.6% → 10.3%，**减半**。*

- 200 → 1,000 (×5): width 10.3% → 4.6%, only ~2.2× narrower.

  *200 → 1,000（×5）：宽度 10.3% → 4.6%，只窄了约 2.2 倍。*

> **To halve the CI width, you must quadruple the sample size.**
>
> ***要把区间宽度减半，样本量必须翻四倍。***

> 💡 **Audit analogy:** to be twice as precise you need four times the sample, and four times the hours. In practice you first set the tolerable error, then work out the sample size. Sarah can ask Priya: "Can you accept ±5% or do you need ±2%?"

# Key Takeaways

*核心要点*

1. **"84%" is a point estimate, not a fact.** A different 200 reviews would give a different number.

   ***"84%" 是点估计，不是事实。**换另外 200 条会得到不同的数字。*

2. **CLT:** whatever the raw data's shape, **sample means become normal** (rule of thumb n ≥ 30), and larger samples give a narrower bell.

   ***中心极限定理**：无论原始数据什么形状，**样本平均值都趋向正态**（经验法则 n ≥ 30），样本越大钟形越窄。*

3. **Standard error** `√(p̂(1−p̂)/n)` tells you how much an estimate wobbles, **without repeating the experiment**.

   ***标准误** `√(p̂(1−p̂)/n)` 告诉你估计值会波动多少，**不用重复实验**。*

4. **95% CI = p̂ ± 1.96 × SE.** Report "84% (95% CI: 78%–89%)".

   ***95% CI = p̂ ± 1.96 × SE。**报告"84%（95% CI：78%–89%）"。*

5. **The 95% describes the method, not this one interval.**

   ***95% 描述的是方法，不是这一个区间。***

6. **√n rule:** halving the width needs 4× the sample.

   ***√n 法则**：宽度减半需要样本 ×4。*

7. **The CLT is why the CI formula works** on binary data like correct/incorrect.

   ***CLT 是置信区间公式能用在对 / 错这种二元数据上的原因。***
